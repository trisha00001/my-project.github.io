Лабораторная работа

Тема: Создание простой веб-страницы средствами HTML и CSS

1. Цель работы

Познакомиться со структурой HTML-документа и научиться создавать простую одностраничную веб-страницу с использованием основных HTML-тегов и базовых CSS-свойств.

2. Задачи лабораторной работы

  • изучить структуру HTML-документа;
  • научиться создавать HTML-файл;
  • использовать заголовки и текстовые абзацы;
  • создавать маркированные списки;
  • добавлять изображения;
  • создавать гиперссылки;
  • добавлять кнопки;
  • применять простые CSS-стили;
  • открывать созданную страницу в браузере и проверять результат.

3. Теоретическая часть

Что такое HTML

HTML (HyperText Markup Language) — язык гипертекстовой разметки, предназначенный для создания структуры веб-страниц.

HTML определяет заголовки, текст, изображения, ссылки, списки, таблицы, формы и кнопки.

<h1>Моя первая страница</h1>

Структура HTML-документа

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Название страницы</title>
</head>
<body>
    Содержимое страницы
</body>
</html>
  • <!DOCTYPE html> — сообщает браузеру, что используется современный HTML.
  • <html> — главный элемент документа.
  • <head> — содержит служебную информацию.
  • <meta charset="UTF-8"> — задаёт кодировку.
  • <title> — название страницы во вкладке браузера.
  • <body> — видимое содержимое страницы.

Основные теги

<h1>Главный заголовок</h1>
<h2>Заголовок раздела</h2>
<p>Текст абзаца</p>
<ul>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
</ul>
<img src="photo.jpg" alt="Фотография">
<a href="https://www.wikipedia.org">Ссылка</a>
<button>Связаться со мной</button>

4. Что такое CSS

CSS (Cascading Style Sheets) — каскадные таблицы стилей, используемые для оформления HTML-страниц.

  • цвет текста и фона;
  • шрифты;
  • размеры элементов;
  • отступы;
  • рамки;
  • внешний вид кнопок.
body {
    background-color: #f2f2f2;
    font-family: Arial;
}

h1 {
    color: darkblue;
}

5. Практическое задание

Создайте небольшой одностраничный сайт «Обо мне».

  1. заголовок с вашим именем;
  2. раздел «Обо мне»;
  3. текст о себе из 3–5 предложений;
  4. раздел «Мои интересы»;
  5. список минимум из трёх пунктов;
  6. одно изображение;
  7. ссылку на любой полезный сайт;
  8. кнопку «Связаться со мной»;
  9. изменённый цвет фона страницы;
  10. изменённый цвет основного заголовка.

6. Создание проекта

about-me/
│
├── index.html
└── photo.jpg

7. Пример HTML-страницы

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Обо мне</title>
    <style>
        body {
            background-color: #f2f2f2;
            font-family: Arial, sans-serif;
        }
        h1 {
            color: darkblue;
        }
    </style>
</head>
<body>
    <h1>Иван Иванов</h1>
    <h2>Обо мне</h2>
    <p>
        Меня зовут Иван. Я изучаю создание сайтов.
        Мне нравится программирование и современные технологии.
        В свободное время я занимаюсь спортом и слушаю музыку.
    </p>
    <h2>Мои интересы</h2>
    <ul>
        <li>Программирование</li>
        <li>Спорт</li>
        <li>Музыка</li>
    </ul>
    <img src="photo.jpg" width="250" alt="Моя фотография">
    <p>
        <a href="https://www.wikipedia.org" target="_blank">Перейти на Wikipedia</a>
    </p>
    <button>Связаться со мной</button>
</body>
</html>

8. Улучшенное оформление

body {
    background-color: #f2f6fa;
    font-family: Arial, sans-serif;
    max-width: 800px;
    margin: auto;
    padding: 40px;
    line-height: 1.6;
}

h1 { color: #173b70; }
h2 { color: #2d5f9a; }
img { width: 250px; border-radius: 15px; }

button {
    background-color: #173b70;
    color: white;
    border: none;
    padding: 12px 20px;
    border-radius: 8px;
    cursor: pointer;
}

button:hover { background-color: #2d5f9a; }
