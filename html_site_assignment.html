Итоговое задание: тематический сайт на HTML

Создайте сайт «Путеводитель по моему увлечению» и опубликуйте его на GitHub Pages.

Срок сдачи: до 1 января 2027 года — не позднее 31 декабря 2026 года. До этого срока предоставьте ссылки на работающий сайт и репозиторий проекта.

Примеры сайтов

Посмотрите примеры студенческих сайтов перед началом работы. Обратите внимание на структуру страниц, навигацию и представление материалов. Примеры служат для знакомства с возможными решениями; ваш проект должен быть самостоятельным и соответствовать требованиям задания.

1. Подготовка: изучите материалы

Перед выполнением задания необходимо ознакомиться с учебными материалами по следующим ссылкам:

  • Курс на Stepik — программа и уроки.
  • JS Institute — образовательные программы и материалы.

В проекте примените темы курса HTML: структуру документа, текст, изображения, ссылки, списки, таблицы, фреймы, мультимедиа, семантические разделы, микроформаты и микроданные. CSS и JavaScript можно использовать дополнительно; обязательная часть задания оценивает владение HTML.

2. Тема и цель проекта

Выберите интересную вам тему: путешествия, кулинария, спорт, музыка, книги, игры или другое увлечение. Сайт должен знакомить посетителя с темой, содержать полезные примеры и ссылки на источники.

Цель: создать содержательный сайт и продемонстрировать применение изученных элементов HTML по назначению.

3. Структура сайта

Подготовьте минимум три связанные страницы:

Файл Содержание
index.html Главная страница: знакомство с темой и обзор сайта.
materials.html Статьи, примеры и медиаматериалы.
about.html Автор проекта, контакты и источники.

На каждой странице укажите <!DOCTYPE html>, язык документа, кодировку UTF-8, уникальный title и настройку области просмотра для мобильных устройств. Используйте header, nav, main и footer. Для самостоятельных публикаций применяйте article, для тематических разделов с заголовками — section, для дополнительного материала — aside. Элементы div и span используйте там, где требуется нейтральная группировка.

4. Текст и форматирование

Добавьте:

  • один основной заголовок h1 на каждой странице и последовательную иерархию подзаголовков;
  • абзацы и смысловое выделение через strong и em;
  • цитату с указанием источника;
  • примеры верхнего и нижнего индексов через sup и sub, например м² и H₂O;
  • пример рубиновой нотации ruby с пояснением её назначения.

Если редкий элемент не подходит к теме сайта, разместите его в отдельной учебной заметке.

5. Изображения

Разместите не менее трёх изображений. Для каждого задайте подходящий alt и размеры через width и height. Хотя бы одно изображение оформите с помощью figure и figcaption. Для изображения ниже первого экрана примените loading="lazy".

Кратко объясните выбор форматов файлов. Используйте собственные изображения либо изображения с разрешённым использованием и укажите источники.

6. Ссылки и списки

Реализуйте:

  • переходы между всеми основными страницами;
  • якорное оглавление хотя бы на одной странице;
  • внешние ссылки на полезные ресурсы;
  • ссылку электронной почты mailto: — допустим учебный адрес с явным пояснением.

Используйте маркированный список ul для перечисления, нумерованный ol для последовательности действий и список описаний dl с элементами dt и dd для терминов и определений.

7. Таблица

Создайте таблицу сравнения объектов по теме сайта: маршрутов, книг, рецептов или инструментов.

Обязательные элементы: название caption, заголовочные ячейки th, разделы thead, tbody и tfoot. Продемонстрируйте осмысленное объединение ячеек через colspan или rowspan. Таблица должна представлять данные, а не использоваться для размещения элементов страницы.

8. Фреймы и мультимедиа

Добавьте:

  1. iframe с атрибутом title, открывающий отдельную локальную HTML-страницу.
  2. Ссылку, открывающую другой документ внутри этого фрейма: свяжите target ссылки с name фрейма.
  3. Аудиозапись и видео с элементами управления controls.
  4. Альтернативные источники через source хотя бы для одного медиаплеера.
  5. Встроенное видео YouTube и обычную ссылку на него.

Для аудио и видео предусмотрите поясняющий текст или расшифровку. Проверьте наличие разрешения на использование медиаматериалов.

9. Микроформаты и микроданные

На странице об авторе оформите контактную карточку с помощью hCard. Добавьте пример hRecipe: тематический рецепт или отдельную учебную демонстрацию.

Один подходящий объект дополнительно опишите микроданными HTML с атрибутами itemscope, itemtype и itemprop. Проверьте разметку доступными валидаторами и приложите результаты проверки. Если отдельный валидатор недоступен, укажите это и поясните, как проверялась структура разметки.

10. Обязательная публикация на GitHub

Загрузите исходные файлы проекта в публичный репозиторий GitHub и опубликуйте сайт с помощью GitHub Pages. Одной ссылки на репозиторий недостаточно: сайт должен открываться в браузере как веб-страница.

Инструкции по загрузке проекта на GitHub:

  • Инструкция — материал в Облаке Mail.
  • Инструкция — материал на Яндекс Диске.

Разместите index.html в корне выбранной папки публикации. Используйте относительные пути к локальным файлам и проверьте регистр символов в именах файлов. После публикации убедитесь, что переходы, изображения, фреймы и медиаматериалы работают на сайте.

В репозиторий не загружайте пароли, ключи доступа и личные данные, которые не предназначены для публичного просмотра.

11. Проверка перед сдачей

  • Все страницы открываются, навигация и якоря работают.
  • Изображения и локальные медиа загружаются на опубликованном сайте.
  • Заголовки организованы последовательно, HTML-элементы используются по смыслу.
  • HTML проверен валидатором; найденные ошибки исправлены.
  • Для заимствованных текстов, изображений и медиа указаны источники.
  • Репозиторий публичный; сайт доступен через GitHub Pages.
  • В README.md приведены тема проекта, структура файлов, ссылка на сайт, перечень выполненных требований и результаты проверки.

12. Что и когда сдать

Не позднее 31 декабря 2026 года предоставьте:

  1. Ссылку на работающий сайт GitHub Pages.
  2. Ссылку на публичный репозиторий с исходным кодом, необходимыми ресурсами и README.md.
  3. Краткое пояснение: какие материалы курса использованы и где реализованы основные требования.

Локальный архив можно приложить дополнительно; он не заменяет публикацию сайта и ссылки на GitHub.

13. Критерии оценки

Критерий Доля оценки
Структура документов и семантика 25%
Текст, ссылки и списки 20%
Изображения и таблицы 20%
Фреймы, аудио и видео 15%
Микроформаты и микроданные 10%
Публикация на GitHub Pages, работоспособность и полнота сдачи 10%

CSS и JavaScript не обязательны. Главное — корректный HTML, содержательность сайта и выполнение требований задания.
